## Dead ends — do not retry

- **Do not prune constraints from a read path.** `snapshot()` is non-mutating by design. Garbage collection
  belongs only in `/act`, the one caller whose timestep is real advancing simulation time. Pruning in
  `/health` or `GET /constraints` destroys live state.
- **Do not filter with a method and serialise the unfiltered field.** `ConstraintSet.active()` is not part
  of the JSON; read endpoints must return `active_snapshot()`.
- **Do not normalise the latency reward by the sum of class weights.** A weighted mean over a single class
  equals that class's value regardless of weight, which cancels the class weighting entirely. Divide by the
  maximum weight instead — `packages/nexus-mdp/src/nexus_mdp/reward.py`.
- **Do not have the controller rebuild the flow set from config.** Flow ids are positional (`f0`..`fn`), so
  a config mismatch produces ids that line up perfectly while the routes behind them belong to different
  flows. Wrong paths, no error. The state carries `candidate_paths` for exactly this reason.
- **Do not decide host locality by substring.** `"localhost" in url` classifies
  `evil-localhost.example.com` as local. Parse the hostname.
- **Do not add `[tool.hatch.build.targets.wheel.force-include]` for `py.typed`.** Hatchling already ships
  every file under `packages = ["src/<pkg>"]`; the force-include grafts a stray top-level `src/` into the
  wheel. I added it, then removed it.
- **Do not catch only `(httpx.HTTPError, ValueError)` in the control loop.** `ActionDecodingError` is a
  `NexusError`, not a `ValueError`.
- **`ruff format` reflows `# noqa` comments across lines**, which silently breaks string-replacement edits
  targeting them. Re-read the file after formatting before editing those lines.
